# Kế hoạch triển khai: Tài liệu dựng lại dự án (SETUP.md)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Một người đi từ máy trắng đến đặt được đơn hàng thật trên local, chỉ bằng cách đọc `SETUP.md` từ trên xuống, không cần mở mã nguồn để đoán bất kỳ biến hay lệnh nào.

**Architecture:** `SETUP.md` ở repo backend là nguồn sự thật duy nhất cho việc dựng lại dự án. Hai file `.env.example` sống cạnh mã nguồn giữ danh sách biến để markdown không lệch được. README của backend bỏ toàn bộ phần cài đặt và trỏ sang `SETUP.md`.

**Tech Stack:** Markdown; đối tượng mô tả là NestJS 11 + Prisma 7 + PostgreSQL (backend) và Next.js 16 + React 19 (frontend).

**Spec:** `docs/superpowers/specs/2026-07-29-setup-doc-design.md`

- [ ] **Step 4: Khởi động thử backend rồi tắt**

Chạy `npm run dev`, chờ tới khi thấy dòng `Prisma connected to DB with adapter` và dòng in cổng, mở `http://localhost:8080/api/docs` xác nhận Swagger lên, rồi tắt tiến trình.

- [ ] **Step 5: Khởi động thử frontend rồi tắt**

Trong `F:\elegant-shop` chạy `npm run dev`, chờ Next.js báo sẵn sàng ở cổng 3000, mở trang chủ xác nhận không lỗi biên dịch, rồi tắt.

- [ ] **Step 6: Đối chiếu chéo lần cuối**

Ba tập khoá sau phải khớp nhau:
1. Khoá trong `.env.example` của backend
2. Khoá trong schema Joi (`src/configs/config.module.ts`)
3. Khoá mà `SETUP.md` nhắc tới

Chạy hai lệnh rồi so bằng mắt (không cần file tạm):

```bash
grep -oE "^[A-Z_]+=" .env.example | tr -d '=' | sort
grep -oE "^\s+[A-Z_]+:" src/configs/config.module.ts | tr -d ' :' | sort
```

Danh sách thứ nhất phải chứa trọn danh sách thứ hai, phần dôi ra đúng bằng ba biến `DEFAULT_ADMIN_*`. Sau đó đọc lại mục 3 của `SETUP.md`, xác nhận nó không liệt kê biến nào vắng mặt trong `.env.example`.

Trước khi commit, chạy `git status` và **đọc cho người dùng nghe danh sách file sẽ vào commit**, gồm cả `src/auth/auth.service.ts`, `test/unit/auth/auth.service.spec.ts`, `test/e2e/cart.e2e-spec.ts` đang dở. Xin xác nhận rồi mới chạy lệnh commit.
